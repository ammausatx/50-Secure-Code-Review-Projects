# 50 Secure Code Review Projects

A practical portfolio of 50 secure code review exercises, organized into 15 Beginner, 20 Intermediate, and 15 Advanced projects. Every project is intended for local training code or repositories you own or are explicitly authorized to review.

> **Training illustration notice:** Each project includes three simulated SVG illustrations. They are fictional instructional mockups, not genuine scanner output, screenshots of live assessments, or proof of client work. Use synthetic identities, code, and data in the exercises.

## Standard project deliverables

Each walkthrough includes:
- Objective, scope, prerequisites, and lab safety boundaries
- Manual review methodology and step-by-step workflow
- Relevant tools, commands, and expected results
- Finding explanation, risk rationale, and CWE/OWASP mapping
- Secure remediation and validation/regression testing
- Evidence/reporting guidance
- Three clearly labeled simulated training illustrations

## Suggested tools

- Manual source review: Visual Studio Code, Git, language/framework documentation
- SAST: Semgrep, CodeQL, and language-native analyzers
- Dependency review: OSV-Scanner and package-manager audit tools
- IaC/container review: Checkov, tfsec, Hadolint, and relevant ecosystem tools
- Validation: framework-native unit/integration tests and local synthetic fixtures

## Safety and evidence

- Review only code you own or have explicit authorization to assess.
- Use synthetic credentials, identities, data, and local fixtures.
- Never publish real secrets, production source, customer information, or private scan output.
- Treat static-analysis alerts as leads; validate source-to-sink reachability and runtime context.
- Clearly distinguish simulated portfolio material from genuine assessment evidence.
